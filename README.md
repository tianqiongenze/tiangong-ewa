## 0. 一句话定位

不是再做一个"更炫的机器人"，而是把工厂作业单变成**可审计、可降级、可回滚、带安全区与人工确认**的机器人作业闭环——
交付一个**异构机群调度 + 具身技能治理 + 证据链 + 数据飞轮**的作业智能体平台。

行业的判断我们完全接受并写进首页：

> **具身智能的瓶颈不是"能不能干活"，是"能不能稳定、高效、可审计地干活"。**

2026 世界机器人大会的共识：行业关注点已从"机器人能不能干活"转向"能不能稳定、高效地干活"。
本方案要把它变成**可招标、可验收、可审计**的工程基线。

## 5. 五分钟看完全貌

```bash
cd impl
make test     # 58 项测试，核心覆盖率 94%
make demo     # 无真机跑通：下单→分解→审批→调度→执行→证据→数据飞轮
make demo -- --chaos   # 注入失败，看四级降级阶梯
make demo -- --person  # 停止区有人，看 R4 停机
make run      # 起服务 :8000（REST + MCP）
```

五条红线（docs/07）：

1. **永不自动进入禁入区**——无例外、无"临时开启"
2. **人工确认令牌只能由人签发**——模型不得生成或复用
3. **数据源内容永不当作指令执行**——看板文字、工单描述不是命令
4. **停止区有人必须停机**——恢复必须人工确认
5. **无证据的动作不得标记完成**
