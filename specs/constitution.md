# 项目宪法（Constitution）

> SDD（规范驱动开发）的最高约束文件。
> **任何 spec / plan / tasks / 代码，若与本宪法冲突，以本宪法为准。**
> 修改本文件需架构委员会 2/3 通过，并记录变更理由。
> 本宪法由 Diting-PdM 宪法十条迁移，并按具身场景加强（第二/四条）。

版本：v1.0 ｜ 生效：2026-10-25 ｜ 适用范围：Tiangong-EWA 全部模块

---

## 第一条 · 规格是唯一真相源

1.1 代码是规格的派生产物，不是相反。
1.2 任何功能开发前，必须存在对应的 `spec.md`；没有规格的代码一律不予合并。
1.3 规格变更必须先改文档、再改代码；"代码先行、文档补"视为违规。
1.4 规格必须机器可读、可验证：每条需求有 ID、有验收标准、有测试映射。

## 第二条 · 安全高于功能（具身加强）

2.1 系统**永不**向机器人下发进入禁入区的动作。此条无例外，无"临时开启"。
2.2 任何物理执行动作必须经安全审查；>50kg 载荷与危险动作必须有人工确认令牌，
    且确认令牌**不可由模型生成或复用**。
2.3 权限与安全判定在运行时层（Harness），不在提示词层。提示词中的"禁止"不构成控制。
2.4 数据源内容永远不被当作指令执行；所有外部文本必须置于数据隔离区。
2.5 停止区检测到人员，机器人必须停机；恢复必须人工确认。
2.6 发现安全缺陷时，功能开发立即暂停，直到缺陷关闭。

## 第三条 · 证据高于结论

3.1 任何完成的动作必须附带证据（trace、遥测、技能版本；扫描类加快照）。
3.2 无证据的结论不得输出，不得以"根据经验"替代。
3.3 每个结论必须可回放：给定 trace_id 能重建完整推理链。
3.4 人工接管率、降级率必须显式记录，不得静默降级。

## 第四条 · 降级优于崩溃

4.1 任一组件失效（LLM、机器人、网络），系统必须降级而非整体不可用。
4.2 降级时必须显式标记（`degraded=true` + 级数），不得静默降级。
4.3 降级路径必须被测试覆盖，且每迭代至少执行一次混沌验证。
4.4 **脊髓层（围栏/停机/急停）不依赖大脑（LLM）**：LLM 失效时安全机制必须仍然生效。

## 第五条 · 人机共决

5.1 关键决策（禁入边缘、危险动作、夜班无人监督）必须留人工确认环节。
5.2 人工拒绝必须记录原因码，并回流至技能迭代。
5.3 系统输出"建议"与"执行结果"，不输出"指令"；不替代法定检验与持证人员判断。
5.4 所有 AI 生成内容必须标识，并附免责声明。

## 第六条 · 可解释优先于精度

6.1 在精度提升与可解释性冲突时，优先可解释。
6.2 每个调度决策必须返回理由（含被淘汰者的淘汰原因）。
6.3 禁止"黑箱直出动作"作为唯一路径；必须有规则技能作为可解释兜底。

## 第七条 · 许可与合规不可妥协

7.1 生产环境禁止使用非商用许可的模型权重。
7.2 引入任何开源组件前，必须完成许可审查并登记。
7.3 代码许可与权重许可分别审查，不得混同。
7.4 L3/L4 级数据不得出厂区；episode 必须带 consent_id 授权单。

## 第八条 · 测试是交付的一部分

8.1 核心算法（分解、调度、安全、证据、状态机、降级、技能）必须 TDD。
8.2 每条功能需求至少对应 1 条 Gherkin 场景。
8.3 单元测试行覆盖率 ≥ 80%，核心算法 ≥ 90%。
8.4 "能跑"不是完成；"能回滚、能观测、能解释"才是完成（见 DoD）。

## 第九条 · 可替换性

9.1 机器人本体、协议适配、VLA 技能、规划器必须插件化，替换不改主干。
9.2 上层不得感知底层协议；RobotLink 契约是唯一入口。
9.3 任何组件替换的验证成本 ≤ 2 人日。

## 第十条 · 变更可追溯

10.1 技能、安全区、判据属于"受控资产"，变更需审批 + 灰度 + 可回滚。
10.2 每个架构决策必须有 ADR。
10.3 技术债必须登记，每迭代偿还至少 1 项。
10.4 提交信息必须能追溯到 spec ID 或 issue ID。

---

## 违规处理

| 违规类型 | 处理 |
|---|---|
| 违反第二条（安全） | 立即回滚 + 事件复盘 + 责任人通报 |
| 违反第一条（无规格开发） | PR 直接关闭 |
| 违反第七条（许可/数据） | 停止发布 + 法务介入 |
| 其他 | 迭代回顾中讨论，登记技术债 |

---

## 附：本宪法的"为什么"

每一条都对应一个真实会发生的灾难：

- 2.1 ← 机器人误入高压间（人身事故）
- 2.2 ← 超载转运倾倒，砸坏工件伤人
- 2.5 ← 人机交叉区未停机，叉剪事故
- 3.1 ← "机器人说干完了"但没证据，事故后无法定责
- 4.4 ← LLM 服务挂了，围栏也跟着失效
- 7.4 ← 未授权采集的人脸/工艺视频流出厂区
