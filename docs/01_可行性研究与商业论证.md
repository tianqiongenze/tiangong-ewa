## 2. 问题定义

### 2.1 客户痛点（设备部/生产部视角）

1. **买了机器人不敢用**：没有安全裁定与人工确认机制，安监不过
2. **用了说不清**：出了事没有证据链，无法复盘与定责
3. **多厂商机群难管**：AMR/四足/人形/臂各一套系统，调度靠人盯
4. **技能迭代不可控**：VLA 模型天天更新，上线靠运气，回滚靠重启
5. **数据白白流走**：实景作业数据不采集，模型迭代永远缺数据

### 2.2 竞品与空白

| 层 | 现有供给 | 空白 |
|---|---|---|
| 本体 | 宇树/智元/优必选/越疆等 400+ 款 | 过剩 |
| VLA 模型 | OpenVLA / π0 / GR00T N1 / NeuroVLA 等 | 快速进步，但**上线治理缺位** |
| 调度中间件 | VDA 5050 类（车队层） | **无语义层**：不懂作业单、不懂安全区、不懂证据 |
| 本项目 | **作业智能体平台** | 补这一层 |

## 3. 方案概述

天工平台五能力：

1. **任务分解**：作业单 → 任务 DAG（规则规划器兜底 + LLM 规划器接口）
2. **异构调度**：能力画像匹配（负载/展幅/传感器/技能/续航/本质安全）
3. **安全运行时**：电子围栏 + 五条红线 + 急停 + 遥操作升级路径
4. **证据与治理**：动作级证据链、技能四态（审批/灰度/回滚）、episode 数据飞轮
5. **开放接口**：REST / MCP / gRPC 三形态；MES/EAM 经 SPI 适配

## 5. 经济可行性（ROI 模型）

以雅迪单基地（年产 50 万台电动车）测算，**保守口径**：

| 项 | 数值 | 说明 |
|---|---|---|
| 替代人工 | 6 个搬运/巡检岗 | 两班制 |
| 单岗年成本 | 8 万元 | 工资+社保+管理 |
| 年节省 | **48 万元** | 6 × 8 |
| 平台投入 | 首期 120 万元（软件 + 适配 + 部署） | Ph1 |
| 机群投入 | 45 万元 | 3 台 AMR + 1 臂 + 1 四足 |
| **回收期** | **约 6.9 个月** | (120+45) / (48/12) |
| 3 年净收益 | 约 200 万元 | 未计数据资产与多基地复制 |

敏感性：若仅替代 3 个岗（回收期约 14 个月）仍显著优于行业基准（服务业机器人 24–36 个月）。

**附加价值（不计入上表）**：
- 实景 episode 数据资产（2026 = 数据元年，训练场/数据服务商有采购需求）
- 多基地复制边际成本趋零
- 与 Diting-PdM 合体："预测性维护建议 → 具身作业执行"全闭环
