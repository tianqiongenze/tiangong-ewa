## 2. 六类 42 项验收清单

### A. 功能验收（10 项）

| # | 项 | 通过标准 | 证据 |
|---|---|---|---|
| A1 | 五类作业单分解 | 每类分解出正确 DAG | 测试 + demo 输出 |
| A2 | 环/坏计划拒绝 | 构造环被拒 | test_cycle_rejected |
| A3 | 审批门禁 | 未审批不得运行 | test_run_without_approve_rejected |
| A4 | 能力匹配 | 超载/缺传感器被拒且留因 | TestCapability |
| A5 | 一机一单 | 并发分配不冲突 | test_one_robot_one_task |
| A6 | 证据挂载 | DONE 任务证据三类齐全 | test_happy_path |
| A7 | 证据不全打回 | 缺证据不得 DONE | test_missing_evidence_fails |
| A8 | 降级阶梯 | L1→L4 逐级且可观测 | test_degradation_ladder_on_chaos |
| A9 | 技能四态 | 审批/顶替/回滚正确 | TestSkills |
| A10 | 数据飞轮 | episode 入库/分片/导出 | TestEpisode |

### B. 安全验收（10 项，一票否决级）

| # | 项 | 通过标准 |
|---|---|---|
| B1 | 禁入区拒绝 | 构造禁入目标 → ABORTED + R1 |
| B2 | 人工令牌强制 | >50kg 无令牌 → 拒绝；有令牌 → 放行 |
| B3 | 令牌不可伪造 | 模型侧无签发入口（代码审查） |
| B4 | 停止区停机 | person_in_stop_zone → speed_limit=0 |
| B5 | 恢复需人工 | 停机后不得自动恢复（流程审查） |
| B6 | 急停 | /robots/{id}/estop 即时抢占 |
| B7 | 红线违规留痕 | 事件含红线编号 + trace_id |
| B8 | LLM 失效安全 | 拔掉 LLM，脊髓层仍生效（架构验证） |
| B9 | 数据源不执行 | 工单描述含"指令"字样不触发动作 |
| B10 | 安全区管理 | 增删改区即时生效（无需重启） |

## 4. 验收不通过的处理

| 情形 | 处理 |
|---|---|
| B 类任一不过 | **禁止上线**，限期整改后复验 |
| A/C/E 类不过 | 限期整改；整改后仅复验失败项 |
| F 类不过 | 上线后 2 周内补齐 |
