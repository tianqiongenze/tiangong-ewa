## 2. REST API（/tg-api/v1）

### 2.1 作业单

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/work-orders` | 下单 + 分解（→ 201，任务 PENDING） |
| GET | `/work-orders` | 作业单列表 |
| GET | `/work-orders/{id}` | 作业单状态 + 报告 |
| POST | `/work-orders/{id}/approve` | 人工审批（→ APPROVED） |
| POST | `/work-orders/{id}/run` | 执行（返回证据链报告） |

下单体：

```json
{
  "kind": "TRANSPORT",
  "params": {"from": "原料库", "to": "装配车间", "what": "电池包",
             "weight_kg": 35, "x": 25, "y": 14},
  "priority": 3, "requested_by": "设备科-老周"
}
```

`kind` ∈ `TRANSPORT | INSPECT | LOAD_UNLOAD | CLEAN | CHARGE`

### 2.2 机群与安全

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/robots` | 机群能力 + 遥测 |
| GET | `/zones` | 安全区清单 |
| POST | `/robots/{id}/estop` | 急停 |

### 2.3 技能治理

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/skills` | 技能与版本状态 |
| POST | `/skills/{id}/versions` | 发布新版本（PENDING） |
| POST | `/skills/{id}/versions/{v}/approve` | 审批 |
| POST | `/skills/{id}/rollback?to={v}` | 回滚 |

### 2.4 数据飞轮

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/episodes/stats` | 总量 / 分片 / 成功率 |

## 3. MCP 服务端（/mcp）

方法白名单：`initialize` / `tools/list` / `tools/call`。

| 工具 | 读/写 | 说明 |
|---|---|---|
| `tg_list_robots` | 读 | 机群状态 |
| `tg_list_zones` | 读 | 安全区 |
| `tg_submit_order` | 写（PENDING） | 下单分解，不执行 |
| `tg_approve_order` | 写 | 人工审批 |
| `tg_run_order` | 写（执行） | 执行已审批作业单 |
| `tg_estop` | 写（安全） | 急停 |
| `tg_episode_stats` | 读 | 飞轮统计 |

调用样例：

```json
{"jsonrpc": "2.0", "id": 3, "method": "tools/call",
 "params": {"name": "tg_submit_order",
            "arguments": {"kind": "INSPECT",
                          "params": {"asset": "焊装线-01",
                                     "points": [{"name": "1号焊机", "x": 20, "y": 14}]},
                          "requested_by": "mcp"}}}
```

## 4. RobotLink 契约（gRPC）

见 `impl/contracts/proto/robot_link.proto`。要点：

- `StreamTelemetry`：机器人 → 平台（含 `person_in_stop_zone` 现场事实）
- `Execute`：平台 → 机器人（**调用前必须已通过安全审查**；带 `human_token` 与 `trace_id`）
- `EmergencyStop`：抢占式急停

adapter 开发约束：

1. adapter 只做协议转换，**不做安全判定**（安全在核心包）
2. adapter 必须透传遥测中的 `person_in_stop_zone`
3. 换厂商 = 新 adapter + 改装配，核心零改动

## 5. 与业务系统集成（SPI）

| 系统 | 方向 | 内容 |
|---|---|---|
| MES | 入 | 工单/排产触发作业单（如"上料"） |
| MES | 出 | 作业完成回写（带 trace_id） |
| EAM | 出 | 设备档案、点检标准 |
| Diting-PdM | 入 | HI 劣化告警 → 自动巡检作业单 |
| 审批流 | 双向 | 令牌签发/审批记录 |

## 6. 版本与兼容

- REST：URI 版本（/v1）；破坏性变更升版本号，旧版保留一个迭代
- MCP：protocolVersion 声明（当前 2025-03-26）
- proto：buf lint 门禁；破坏性变更走 `breaking: FILE`
