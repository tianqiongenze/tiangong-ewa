## 1. 项目定义

**名称**：天工 · 具身智能工厂作业智能体平台（Tiangong · Embodied Work Agent Platform）

**定位**：面向多基地制造集团的具身智能**作业编排与治理平台**。向上接工厂业务系统（MES/EAM/WMS），向下接异构机器人群（AMR/四足/人形/机械臂/协作臂），中间用智能体完成"意图 → 任务 → 调度 → 执行 → 证据 → 沉淀"的闭环。

**它不是**：机器人本体、VLA 模型训练框架、又一个大屏。

**它是**：让已有/在购的机器人**敢上线、能验收、可审计**的那一层。

---

## 2. 商业论证摘要（详见 docs/01）

- 市场：2026 中国具身智能市场破**万亿**；政策端"实景实训"专项行动要求年底形成百个以上高价值场景
- 痛点：行业"Demo 多、订单少"，卡在**稳定性、可审计性、安全性**，不是卡在能力演示
- 价值主张：把"机器人干活"变成"**带证据的作业合同**"——每个动作有 trace、有技能版本、有安全裁定、有人工确认点
- 付费方：制造企业设备部/生产部（省人工 + 可验收），机器人厂商（缺这一层软件），数据服务商（缺实景数据）

## 3. 范围

### 3.1 首期范围（Ph1，本文档基线）

| 维度 | 范围 |
|---|---|
| 场景 | 五类作业单：搬运 / 巡检 / 上下料 / 清洁 / 回充 |
| 机群 | AMR + 机械臂 + 四足（仿真 + 协议契约；真机适配后置） |
| 部署 | 单基地演示 → 总部 + 2 基地（与 Diting-PdM 同节奏） |
| 系统集成 | REST/MCP 对外；MES/EAM 适配留 SPI |
| 数据 | episode 采集 + 分片导出（数据飞轮最小闭环） |

### 3.2 明确不做（首期）

- 不做机器人本体与运动控制（VLA 小脑层由合作方/开源模型提供）
- 不做视觉算法训练平台（只做 episode 采集与导出）
- 不向 PLC/DCS/SIS 下发控制指令（与 Diting-PdM 同纪律）
- 不做全无人夜班（首期保留人工确认点）

## 4. 总体策略：软硬分层，契约先行

```
┌─────────────────────────────────────────────────┐
│ 业务层   MES/EAM/WMS  ⇄  作业单入口 / 结果回写     │
├─────────────────────────────────────────────────┤
│ 智能层   天工 agent-runtime                       │
│          （分解/调度/安全/证据/技能/飞轮）          │
├─────────────────────────────────────────────────┤
│ 链路层   RobotLink 契约（gRPC / VDA 5050）        │
├─────────────────────────────────────────────────┤
│ 本体层   AMR / 四足 / 人形 / 机械臂（多厂商）       │
└─────────────────────────────────────────────────┘
```

**契约先行**：`impl/contracts/proto/robot_link.proto` 先行定义，真机适配关在各厂商 adapter 里，
平台不感知协议差异（可替换性，宪法第九条）。

## 6. 风险与对策（Top 5）

| # | 风险 | 等级 | 对策 |
|---|---|---|---|
| R1 | 真机 VLA 成功率不稳定 | 高 | 降级阶梯 + 规则技能兜底；首期选确定性高的场景 |
| R2 | 安全事件（人机交叉） | 极高 | 五条红线 + 停止区停机 + 急停 + 人工确认点（docs/07） |
| R3 | 厂商协议封闭 | 中 | 契约先行 + adapter 模式；VDA 5050 兜底 |
| R4 | 数据合规（厂内视频/人脸） | 高 | episode 脱敏 + consent_id 授权单 + 数据不出厂区 |
| R5 | 交付周期 | 中 | Ph0 只交软件闭环（仿真），真机联排后置 |
