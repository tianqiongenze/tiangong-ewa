## 3. 混沌与降级验证


## 4. 质量门禁（CI）

```yaml
ruff check packages services        # 静态检查（规则集见 impl/pyproject.toml）
pytest -q --maxfail=1               # 96 项全量测试
coverage report --fail-under=80     # 覆盖率门禁（当前 93%）
python tools/demo_run.py            # 演示冒烟（无硬件）
buf lint contracts/proto            # 契约 lint
```

lint 规则说明：`per-file-ignores` 对 `app/` 层放行 `BLE001/S110/S112`（宽泛捕获与静默忽略），
理由是**降级纪律要求**——基础设施（缓存/事件/追踪）故障必须被吞掉并降级，不得中断主链路；
该放行仅限 `app/` 层，`tiangong_core` 保持严格（异常必须显式）。

## 6. DoD（Definition of Done）

一条任务"完成"的判据（与运行时的 DONE 判据对齐）：

1. 有规格（spec ID）
2. 有测试（覆盖新增分支）
3. 有证据（trace/遥测/技能版本）
4. 过门禁（CI 全绿）
5. 可回放（trace_id 重建）
6. 文档同步（受影响文档已更新）

> "能跑"不是完成；"能回滚、能观测、能解释"才是完成。
